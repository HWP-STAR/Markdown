# ONNX
ONNX（中间格式）：扮演“通用翻译官”的角色。PyTorch、TensorFlow等不同框架有自己的“方言”，ONNX定义了一套标准的“通用语言”。模型先被翻译成ONNX格式

TensorRT（优化编译器）：扮演“资深工程师”的角色。它读取ONNX这个“通用图纸”，然后针对你的具体NVIDIA GPU型号，进行极致优化（融合层、选最优算法、做量化等），最终生成一个专属的、高度优化的引擎（Engine）。

TRT Runtime（执行器）：扮演“操作工”的角色。它只负责在应用程序中加载并运行TensorRT生成的那个引擎文件。

流程总结：PyTorch模型 --导出--> ONNX文件 --输入--> TensorRT（优化器） --生成--> TRT引擎文件 --加载到--> TRT Runtime --执行--> 推理结果
