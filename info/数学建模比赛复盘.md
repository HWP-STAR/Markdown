# 1. 数据理解与预处理技能
数据清洗：处理缺失值、异常值，整合多张数据表（如商品信息表和销售流水表）。

探索性数据分析：通过统计描述、分布检验（如K-S检验）等初步了解数据特征。

# 2. 统计分析与规律探索方法
用于解决第一问，通常是分析数据的内在规律和相互关系。

相关性分析：使用皮尔逊相关系数等方法分析品类/单品间的关联，并用热力图可视化。

主成分分析：当指标众多时，用PCA降维，提取关键因素。

聚类分析：用于对样本或指标进行分类。

# 3. 优化建模与决策方法
这是C题的“重头戏”，通常用于在约束下寻找最优方案。

规划模型：线性规划、整数规划（含0-1规划）是核心工具，用来处理资源分配、生产计划等问题。

多目标规划：当需要同时优化多个目标（如最大化收益、最小化成本）时使用。

高级优化：对于复杂问题，可能需要动态规划或启发式算法（如遗传算法）。

# 4. 预测与评估方法
时间序列分析：如ARIMA、指数平滑等，用于预测未来的销量或需求趋势。

综合评价方法：如熵权法、TOPSIS，用于对方案进行综合排序和评价。

降温：逐渐降低探索程度
接受准则：差解也可能被接受（避免局部最优）
生活类比：登山时，先大范围探索（高温），再慢慢锁定最佳路线（低温）

# A题
按标准结构写：摘要→问题重述→模型假设→符号说明→模型建立与求解→模型检验与灵敏度分析→模型评价与推广→参考文献→附录


- 审题与机理分析是核心：拿到题目后，先别急着套模型。要花时间弄清背后的物理过程，明确研究的对象遵循哪些物理定律。可以画出物理过程示意图，标出关键变量和参数。

- 合理假设，简化问题：现实问题通常很复杂，需要根据题目要求做出合理的简化假设（如忽略空气阻力、假设物体为刚体等）。这些假设是建立可求解模型的基础，但必须合理，并在论文中明确说明。

- 建立机理模型：在假设的基础上，用数学语言（如微分方程、代数方程组）来描述物理规律，这就是你的核心模型。对于A题，模型的“物理正确性”比数学上的复杂技巧更重要。

- 重视模型验证与结果分析：求出结果后，需要验证其合理性。可以通过量纲分析、与已知物理规律对比、改变参数做敏感性分析等方式来检验模型。最后要结合物理意义解释你的结果。

# 共性亮点
- 摘要极其出彩：评委先看摘要。要写清“建了什么模型、用什么方法、得到什么结果、误差多大、模型有什么特色”，两三句话内抓住核心创新点。

- 模型有“巧劲”：不是堆砌复杂公式，而是对题目背景有深刻理解。例如把实际问题抽象成偏微分方程、优化模型或图论模型，并解释为什么这个方法合适。

- 假设合理且论证充分：重要假设都解释了物理/工程依据，并且做了“如果假设不成立会怎样”的讨论。

- 结果可视化程度高：有清晰的三维图、热力图、对比图、轨迹图。图表本身就能讲出故事。

- 模型检验和灵敏度分析是“重头戏”：获奖论文几乎都有至少一节的“模型验证”和“参数灵敏度分析”，而不仅仅是完成任务。

- 代码规范、附录完整：评委可能会抽查代码，如果你的代码结构清晰、注释清楚、可复现，会加印象分。

## 模型检验
- 极限/退化检验​
让参数趋于0或无穷大，看模型是否退化成已知简化情形

- 解析解对比​
和经典解析解（如热传导的傅里叶解、简谐振动解）做对比
- 网格/步长无关性​
加密网格或减小步长，看结果变化是否在可接受范围

- 数值稳定性检验：对同一模型用 Radau、BDF、LSODA 三种方法求解，比较结果，验证刚性求解器选择的合理性。
- 能量/质量守恒检验：计算全时空的能量守恒残差和干物质质量守恒残差，量级应接近机器精度（如 < 1e-6）。
- 交叉验证：各个问题的交叉验证

# 灵敏度分析

- 对关键参数做 ±10%、±20% 扰动，看结果变化；

• 多参数联合扰动：不只是单个参数±10%、±20%，可以做一个“参数扫描”，比如同时扰动两个关键参数，画出等高线图或热力图，观察是否存在交互效应。

• 灵敏度指数：计算归一化灵敏度系数  

  \[
  S = \frac{\Delta R / R}{\Delta p / p}
  \]
  然后对参数影响力排序，找出“最关键参数”。

- 给出灵敏度图或表，说明模型稳不稳定；

• 模型局限性讨论：明确指出模型适用于什么范围，超出范围会怎样。

• 与简化模型对比：比如你的全模型结果和忽略某个因素后的结果差异大小，说明该因素的贡献。



# 算法总流程图
==========================


###  模型检验

**（1）极限/退化检验**

- 问题1：令 \(h\to\infty\)，表面温度应瞬时等于 \(T_\infty\)；
- 问题2：令 \(L_v\to0\)，结果应接近问题1；
- 问题4：令 \(R(t)\equiv R_0\)，结果应等于问题3。

**（2）解析解对比（仅问题1）**

问题1在忽略表面水分通量时，温度方程有解析解：

\[
T(r,t) = T_\infty + \sum_{n=1}^\infty A_n J_0\left(\frac{\mu_n r}{R}\right)e^{-\alpha\mu_n^2 t/R^2}
\]

其中 \(\mu_n\) 是 \(J_0\) 的零点，\(A_n\) 由初始条件确定。与数值解对比，验证空间二阶、时间高阶精度。

**（3）网格/步长无关性（问题1-2）**

\(N=10,20,40,80\)，比较 \(t=1800\,\text{s}\) 时 \(T(r)\) 和 \(C(r)\) 的最大偏差。判据：\(N=20\to40\) 时偏差 < 0.1%。

**（4）数值稳定性检验（问题2-3）**

对比 Radau、BDF、RK45：

- RK45 在刚性区域步长急剧减小或失败 → 证明系统刚性；
- Radau 和 BDF 结果一致 → 证明刚性求解器选择合理。

**（5）守恒检验（问题2-4）**

- 干物质质量：\(\int_0^R \rho_d\cdot 2\pi r\,dr = \text{const}\)，误差 < \(10^{-6}\)；
- 总水量：\(\frac{d}{dt}\int_0^R C\cdot 2\pi r\,dr = -2\pi R k_m(C_s-C_\infty)\)；
- 总能量：\(\frac{d}{dt}\int_0^R \rho c_p T\cdot 2\pi r\,dr = 2\pi R[h(T_\infty-T_s)-L_v k_m(C_s-C_\infty)]\)。

**（6）交叉验证**

- 问题2 vs 问题1（短时，\(L_v=0\)）；
- 问题3 vs 问题2（前3h）；
- 问题4 vs 问题3（\(R\equiv R_0\)）。

###  灵敏度分析

**（1）单参数扰动**

对 \(h, k_m, L_v, D_0, E_a\) 做 ±10%、±20% 扰动，输出 \(t_{\text{dry}}\) 和 \(T_s(3\text{h})\) 的变化。

**（2）多参数联合扰动**

选择 \(h\) 和 \(k_m\)（或 \(D_0\) 和 \(E_a\)），做 \(5\times5\) 网格扫描，画等高线图。

**（3）灵敏度指数**

\[
S_p = \frac{\Delta t_{\text{dry}}/t_{\text{dry}}}{\Delta p/p}
\]

排序：\(|S_p|\) 越大越敏感。

**（4）模型局限性**

明确每个问题的适用范围和超出范围的后果。

**（5）与简化模型对比**

量化蒸发项、收缩、长时间刚性对各问结果的贡献。
