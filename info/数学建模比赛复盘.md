# 1. 数据理解与预处理技能
数据清洗：处理缺失值、异常值，整合多张数据表（如商品信息表和销售流水表）。

探索性数据分析：通过统计描述、分布检验（如K-S检验）等初步了解数据特征。

# 2. 统计分析与规律探索方法
用于解决第一问，通常是分析数据的内在规律和相互关系。

相关性分析：使用皮尔逊相关系数等方法分析品类/单品间的关联，并用热力图可视化。

主成分分析：当指标众多时，用PCA降维，提取关键因素。

聚类分析：用于对样本或指标进行分类。

# 3. 优化建模与决策方法
这是C题的“重头戏”，通常用于在约束下寻找最优方案。

规划模型：线性规划、整数规划（含0-1规划）是核心工具，用来处理资源分配、生产计划等问题。

多目标规划：当需要同时优化多个目标（如最大化收益、最小化成本）时使用。

高级优化：对于复杂问题，可能需要动态规划或启发式算法（如遗传算法）。

# 4. 预测与评估方法
时间序列分析：如ARIMA、指数平滑等，用于预测未来的销量或需求趋势。

综合评价方法：如熵权法、TOPSIS，用于对方案进行综合排序和评价。

# 对于3中的现代优化算法
1. 遗传算法（GA）- 模仿生物进化
核心思想：像自然界的"优胜劣汰，适者生存"
关键概念：
个体：一个候选解
种群：一组候选解

3. 模拟退火（SA）- 模仿金属退火过程
核心思想：通过"温度"控制探索和利用的平衡
关键概念：
温度（T）：控制接受差解的概率
降温：逐渐降低探索程度
接受准则：差解也可能被接受（避免局部最优）
生活类比：登山时，先大范围探索（高温），再慢慢锁定最佳路线（低温）
