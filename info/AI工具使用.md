2. 视觉截图

## 操作
1.辅助功能动作（最高优先级）：对于支持辅助功能 API 的应用，ChatGPT 可以直接调用 API 来“按下”某个按钮或“设置”文本框的值。这就像直接命令应用“执行这个动作”，无需模拟鼠标移动
系统级输入注入（通用后备）：如果某个应用不支持辅助功能动作，ChatGPT 就会模拟真实的用户输入。它会向操作系统发送底层的鼠标点击、键盘按键事件（如 macOS 的 CGEventPost）。从操作系统的角度看，这与真实的键盘鼠标硬件输入几乎没有区别，因此绝大多数应用都会响应。

多后端回退链：为了最大化兼容性，一些实现（如 Screen Agent）采用了明确的回退链：Accessibility API → CGEvent → pyautogui。如果第一层失效，就尝试第二层，以此类推，从而覆盖从原生应用到游戏引擎等各类软件
