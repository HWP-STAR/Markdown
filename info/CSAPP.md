 # 数的表示
 - 无符号（unsigned）编码基于传统的二进制表示法，表示大于或者等于零的数字
 - 补码 （two's-complement）编码是表示有符号整数的最常见的方式，有符号整数就是可以为正或者为负的数字
 - 浮点数（floating-point）编码是表示实数的科学记数法的以 2 为基数的版本

 - 对于浮点数：计算机用有限的二进制位，表示无限的十进制小数，必然出现“舍入误差”。

有限 十进制小数 可能是 二进制无限循环
- 局限 1：精度有限（舍入误差）
- 局限 2：不是所有小数都能精确表示
- 有“特殊值”，不是真正的数字

nan /inf等

# int和float的区别
整数的表示虽然只能编码一个相对较小的数值范围，但是这种表示是精确的；
而浮点数虽然可以编码一个较大的数值范围，但是这种表示只是近似的

# 1字节（byte）=8位（bit），0-255,或 00-ff
字节是最小单位,一般使用16进制表示（0x）
16进制转2进制：直接将16进制（hex）数单个展开为4个2进制数就行，4位一组

eg：int 占4字节，字节用来存储address
没有前最0x,则一般是10进制

# byte 和 word

bit -> byte -> MB -> GB -> TB等
word CPU运算单位，CPU 最喜欢按 Word 干活，一次运算的可处理数据单位（有32 bit/64 bit）

# 位操作
& is and , | is or , ^ is xor (只有一个是1)，～ is 取反

## 位移 操作
<< n , 左位移动n，相当于*2^n
>> n , 右位移动n，相当于/2^n ，右移负数：逻辑右移和算术右移结果不同
- 算术右移 >>：补符号位（算术操作用这个）
- 逻辑右移 >>>：补 0
用来：
- 高效乘除法
- 底层数据打包
- 一般在底层使用


# 条件判断
&& is and, || is or

# 补码
最高位（左边）0 是正数，直接算
最高位1是负数，取反，+1 变成正数（可逆变化）

8 位补码范围：-128 ～ +127，把0加入正数中，刚好一半
- 加法天然正确

只要不溢出，补码和无符号数可以直接算

无符号 == 有符号 if 在有符号正数范围内
负数不对应

# int 默认是有符号整型（signed int），补码是主要的使用方式
int ≡ signed int，可以存正数、负数、0
运算溢出会得到一个负数
