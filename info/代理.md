# 代理使用

方式 A：给 Git 单独设置代理（推荐）
bash
运行
# 先清空旧配置，避免残留冲突
git config --global --unset http.proxy
git config --global --unset https.proxy
# 填入你自己端口
git config --global http.proxy socks5h://127.0.0.1:7890
git config --global https.proxy socks5h://127.0.0.1:7890


方式 B：终端全局环境变量
bash
运行
export ALL_PROXY=socks5h://127.0.0.1:7890
export http_proxy=socks5h://127.0.0.1:7890
export https_proxy=socks5h://127.0.0.1:7890

unset ALL_PROXY
unset http_proxy
unset https_proxy

git clone https://ghproxy.com/https://github.com/xxx/xxx.git
export HF_ENDPOINT=https://hf-mirror.com
