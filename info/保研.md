# 学术专长原则上仅限：
本科阶段在核心期刊以独立作者或第一作者发表与学业相关的科研论文；或
作为主力成员参加与学业相关的国内权威科研竞赛（全国赛）获三等奖及以上（国际赛参照，不低于国内要求）。
与直系亲属、或职称/学历/职务明显高于本人者合作的成果、奖项：仅作参考，不计入推免综合成绩。
学院成立专家审核小组（副教授及以上，≥5人），可组织公开答辩；抄袭、挂名、冒名、有名无实的不认。
学业成绩占综合成绩 ≥70%；科研/竞赛/志愿/服役/国际组织实习等加起来不超过 30%。

# 论文
论文署名单位不是“只能数院”，而是看“深圳大学 + 与学业/数学相关 + 作者位次 + 学院审核”。
一般前三作者才有用

## 分级
传统理工医：
SCI 一区 > SCI 二区 > SCI 三区 > SCI 四区

在计算机/AI 圈：
CCF-A 会议 ≈ 甚至 > SCI 一区顶刊
CCF-B 会议 ≈ SCI 二区左右（有时比普通二区更受同行认）
CCF-C 会议 ≈ SCI 三区/四区或高质量 EI 期刊，看具体会

# 要求
- 做志愿，思政学分，讲座
- 成绩3.5
可减少：
3.以深圳大学作为第一署名单位，作为独立作者或第一作者，在中科院一区期刊发表学术论文（以中国科学院文献情报中心JCR期刊分区表中大类分区升级版为准）。中科院一区期刊以申请推免当年的最新分区表为准，论文发表的录用通知无效，需提供正式发表的刊物原件及知网、Web of Science 等数据库的检索证明。通讯作者若为校内教师，应出具非直系亲属及学术指导无利益关联的书面说明。

- 大学英语四级考试成绩达到500分及以上，或六级考试成绩达到425分及以上

- （四）推免生承诺本科毕业后无赴境外留学、直接就业计划、参加公务员考试等非攻读本校或外校研究生的计划，签订书面承诺书，若违反承诺书约定，取消推免资格并承担相应责任。

- （五）已达到预毕业资格审查条件。

# 殊学术专长，具体要求为：

（一）推免生的学术专长原则上仅限学生本科阶段在核心期刊上以独立作者或第一作者发表的与学业相关的科研论文或者作为主力成员参加与学业相关的国内权威科研竞赛（全国赛）并获得三等奖及以上奖励（国际赛事参照执行，但不得低于国内赛事相关要求）。学生与直系亲属或学历、职称、职务明显高于本人者合作的科研成果、竞赛奖项等仅作为参考，不纳入学生本人推免遴选综合评价成绩计算体系，同等条件下可优先考虑。
