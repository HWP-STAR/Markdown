# LingBot-World 2.0

强在 “无限时长、视觉不崩”  稳定性

主要功能（无限时长、实时交互、丰富动作）、核心组件（预训练+蒸馏模型、Agent框架）

# 1
抗漂移的因果预训练（Anti-drift Causal Pretraining）

技术点：提出 MoBA（混合双向与自回归注意力掩码）。传统因果模型只用“教师强制（Teacher Forcing）”训练，导致模型过度依赖干净的历史帧而丧失预测能力（质量下降）。MoBA在训练时，在自回归掩码的末尾拼接一个小的双向注意力块。
# 2
两步走的后训练蒸馏（Two-stage Post-training Distillation）

技术点：先使用一致性蒸馏（CD） 将50步生成压缩到几步；再使用分布匹配蒸馏（DMD） 进行对抗性微调。

智能体编排框架（Director-Pilot Co-Simulation）

技术点：将VLM（视觉大模型）作为“导演（Director）”进行宏观因果推理，将视频生成模型作为“飞行员（Pilot）”执行底层像素渲染。

作用：VLM负责理解“射箭会导致什么”，视频模型负责执行“箭飞出去的样子”，两者解耦，让模型具备了语义级别的逻辑推理能力，而非仅做像素层面的运动预测。

动态KV缓存调度（Dynamic KV Cache Management）

技术点：不是保留所有历史帧，而是根据当前的控制信号动态丢弃不相关的历史信息。

作用：既保证了60fps的实时吞吐量，又通过剔除冗余信息抑制了长尾干扰，提升了画质连贯性。


# 局限性”（Limitation）
缺乏真正的长期记忆：模型虽然视觉上稳定，但“记不住”自己生成过什么。当某个区域离开上下文窗口再回来时，会被重新生成，而非“回忆”起来。这导致世界在“身份”上是不连续的。

身份与风格漂移：在超长生成中，特定角色的外貌或整体画风可能会有微妙的改变。

物理理解不完美：模型是从像素中学习的，没有内置物理引擎，所以偶尔会出现物体穿插等不符合物理规律的“幻觉”。

计算资源需求高：即使经过蒸馏，要在单卡上达到完美体验仍有距离。

# 3
必须让生成模型（大脑）、调度算法（神经）、智能体逻辑（思维）和工程流水线（手脚）高度配合

输入解析：系统接收W键指令。

Director干预：VLM判断“前方是空地”，生成提案“角色向前走”。

信号转换：Pilot把提案转为具体的相机轨迹和Prompt。

生成执行：1.3B蒸馏模型根据历史帧和该指令，1步生成新帧。

加速输出：VAE异步解码，立即推流到屏幕。

世界演化：同时，Director发现“世界太安静了”，主动在后台提案“让一朵云飘过”，用户甚至不需要按任何键，世界也在自主变化。


Diffusion（扩散模型）：从一堆噪声开始，一步步"擦干净"，得到一张图 / 一段视频。像画家反复涂改一幅混沌的画，越改越清晰。
因果自回归（Causal Autoregressive）：从左往右、从前到后，一个接一个地生成，后面每一步都只能看前面的内容。像打字员一个字一个字敲，不能回头改前面写好的。

# Matrix-Game 3.0
最大的独特卖点：长期记忆（Memory）机制

核心贡献（四合一系统）：

错误感知（Error-Aware）基础模型：通过“收集-注入”生成错误，让模型学会自我纠错，避免长时漂移。

相机感知（Camera-Aware）长期记忆机制：通过检索历史帧（基于相机视角重叠度）并注入当前生成，实现场景重访时能“回忆”之前的内容，而非重新生成。

训练-推理对齐的多段蒸馏：基于 DMD（分布匹配蒸馏），让蒸馏模型在多段自回归 rollout 上训练，而非单段，消除训练与推理的分布偏差。

实时推理加速：INT8 量化 + VAE 剪枝（MG-LightVAE，最高剪枝75%，速度提升5.2倍）+ GPU 检索，最终实现 5B 模型在 720p 下 40 FPS 实时生成。
