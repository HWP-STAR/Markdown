1. 查看本地所有分支（你电脑上的）
bash
运行
git branch
看远程仓库的分支（GitHub/GitLab/ 码云 上的）
bash
运行
git branch -r  or -a


# 1. 切到主分支
git checkout main

# 2. 新建并切换到你的功能分支
git checkout -b feature/login

# 3. 写代码后提交
git add .
git commit -m "完成登录功能"

# 4. 第一次推送到远程（必须加 -u）
git push -u origin feature/login

# 5. 要合并时：切回主分支 → 合并 → 推送
git checkout main
git merge feature/login
git push
