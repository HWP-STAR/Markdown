# 可穿戴六轴 IMU 
IMU（Inertial Measurement Unit，惯性测量单元）​ 是一种通过惯性原理测量物体运动状态的传感器模组。六轴 IMU​ 内部集成了两类传感器，共六个测量轴：
三轴加速度计（3-axis Accelerometer）：分别沿 X、Y、Z 三个正交轴，测量线性加速度（包括重力加速度），可感知设备的倾斜、震动、冲击和直线运动。
三轴陀螺仪（3-axis Gyroscope）：同样沿 X、Y、Z 三轴，测量角速度（物体绕各轴的旋转速率），可感知设备的旋转、翻转、偏航等姿态变化。

# 作用
实时感知设备在三维空间中的运动与姿态

# RSRW 是一种在训练时给每个样本分配权重的策略，
权重由“类别稀有度、鲁棒难度、真实/合成可靠性”三部分决定；所有计算都用 detached logits 和小批量统计，只做一阶、stop-gradient 加权，不传二阶梯度。

# WGAN（Wasserstein GAN）
改进的GAN方法，用来生成数据
用 Wasserstein 距离（推土机距离，Earth Mover's Distance）替代 JS 散度，来衡量真实分布与生成分布之间的差距

# CGN
一种能显式控制形状、纹理、背景并生成反事实图像的生成模型

- 问题
针对的是深度分类器中的 shortcut learning / spurious correlation 问题

- 方法
CGN 的独立机制（Shape 机制，texture 机制,background 机制）

每个头对各自因素敏感、对其他因素不变，集成输出。

- 效果
OOD 鲁棒性就是指：模型在测试分布与训练分布不一致时，仍能保持较好性能的能力

推理时，可以对每个机制独立随机化标签和噪声，生成训练集中不存在的反事实组合，例如“猫的形状 + 大象的纹理 + 草地背景”。

# GeSSL (自监督学习)
## SSL
从数据自身构造"伪标签"（pretext task），让模型自己教自己学习有用的特征表示。

少样本：先预训练（自监督），后标签训练

核心机制：Pretext Task（前置任务）
eg：人为构造任务（如：遮挡一部分，让模型预测）
eg：掩码语言建模，预测下一个token

## 分类
判别式 SSL：模型学的是"哪些数据应该相似、哪些应该不同"——像在做判断题/选择题
eg：对比学习

生成式 SSL：模型学的是"数据长什么样，能不能还原/生成数据"——像在做填空题/默写题
eg：GPT

## 问题
SSL 模型可能会“走捷径”——利用数据中的表面线索（而非语义本质）来完成前置任务，导致学到的特征“看起来有用，实际上脆弱”。


## 效果
GeSSL 可插拔地提升多种 SSL 基线，且计算开销适中、收敛更快。

## 方法
SSL 原来的问题就是：模型经常靠“背景像”“颜色像”“增强痕迹像”来认，而不是靠“东西本身”

- 必要性
如果两个东西语义上不是一回事，哪怕表面再像，也不能认。
GeSSL 给每个样本学一个“接受边界”

可能过度敏感

- 充分性
如果语义没变，只是背景、颜色、风格、遮挡变了，关系要保持稳定。
Support-Query 检验

可能过度稳定

### 2
SSL 的监督不是标签，而是“关系”
监督信号来自数据自己构造出来的关系

### 3
把数据分成 support 和 query 两拨
三个东西都来自同一个源样本，只是经过不同增强/损坏。

### 可自由增加
GeSSL只要求你提供一个基础 SSL 损失
对同一个源图，生成三个视图

原来：基础对比损失，基础 SSL loss
增加：判别关系损失
         额外加一个 g（外层（query）） 和 L_disc（内层（support））
                ↓
         support 学，query 考
                ↓
         更新 f 和 g

- 就是多插一个约束（L_disc）和一层检验（support-query 双层）

## 理解
- 必要性：语义变了，模型要翻脸；
- 充分性：语义没变只是 nuisance 变了，模型别翻脸。
但真实语义因素和 nuisance 因素在 SSL 里不可观测，不能真的做干预。所以 GeSSL 不直接实现原则，而是找训练时能算的代理去近似它们。

proxy是替代指标
GeSSL 是对“反事实模型可靠性”的可训练近似，就是模型是否真的学会语义

- 实验
    - 有效性：GeSSL 加到不同 SSL 上有没有提升
    - 为什么有效：消融与分析
    - 代价多大：效率与收敛
